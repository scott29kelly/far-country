# GA-2 reference set — provenance

Every image here is public domain or CC0 and was license-verified through
the Wikimedia Commons API at download time (2026-08-19). The set is the
aesthetic bar for gauntlet runs (docs/plans/gauntlet-adoption-far-country.md
GA-2): critics judge our stills against these for material response,
lighting, and atmosphere — NEVER for content. Swapping or adding a
reference is a logged decision (STATUS.md), not a casual edit. Scott
approves the set before any gauntlet run uses it.

Standing sentence-form bar: a stranger flipping between our still and a
reference photo should hesitate before saying which is the render.

The scene's fixed light is timeOfDay 17.0 (NJ_CONFIG.look) — late
afternoon, low warm sun. The sky/ images were chosen for that hour;
midday images elsewhere are material/structure references, not light
references.

MOOD references (what the city should feel like) are Scott's own concept
renders and are NOT in this folder — see MOOD-REFS.md. Only MATERIAL /
STRUCTURE / ATMOSPHERE photography lives here.

Curation notes (2026-08-19 first pass): three initial picks were replaced
after visual review — the original "Grand View Point (8971039797)" turned
out to be a PAINTING (artist-in-residence work, unusable for a photoreal
bar), the Katmai "Dumpling Overlook" image was a forest trail not a
meadow, and the Capitol Reef "low clouds" image was winter fog. Several
kept images show winter conditions or human elements (bikers, quarry
machinery) — flagged in their role column or visible in _contact.jpg;
Scott's approval pass decides whether they stay.
